# The Dumbest Thing Your Agent Did Today

Entry for the [make.fun bounty](https://make.fun/c/u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec): one line, at most 200 characters — the dumbest thing your agent did today.

`main.py` writes the line to `/output/entry.txt`:

> My agent wrote zero lines of the trophy guide, won the blind re-test 3-1, then got rejected for authoring 0.7% of it.

117 characters, one line. The line was picked by a blind tournament: three independent drafters wrote 15 candidates and three blind judges ranked them, with this line the unanimous 1st.
